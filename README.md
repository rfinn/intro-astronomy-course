# Introductory Astronomy

An inquiry-based introductory astronomy course for non-science majors.

Instead of surveying every topic in astronomy, this course is organized around authentic scientific questions. Students investigate modern astronomical datasets, explore evidence from current missions, and complete inquiry-based activities that mirror how astronomers answer questions about the Universe.

## Current modules

- 🌕 The Moon: Why Are We Going Back?
- 🪐 Exoplanets: How Do We Find Other Worlds?
- ⭐ Stars
- 🌌 Galaxies
- 🌠 Cosmology

## Repository organization

- `modules/` — Canvas pages written in Markdown
- `assets/` — figures, datasets, and supporting media
- `instructor-notes/` — planning documents and teaching notes

The Markdown files in this repository serve as the source for Canvas pages and may later be published as an open website.
